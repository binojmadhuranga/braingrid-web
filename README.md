# BrainGrid Frontend

AI-powered student productivity and learning platform built with Next.js.

---

## 🚀 About BrainGrid

BrainGrid is a modern SaaS platform designed to help students improve productivity, learning, note management, and study workflows using AI-powered tools.

This repository contains the frontend application built with:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Axios
- JWT Authentication

---

# ✨ Features

- 🔐 User Authentication (Register/Login)
- 🎯 JWT-based Protected Routes
- 🤖 AI-Powered Study Assistant
- 📝 Smart Notes Management
- 📚 Task & Study Planner
- 📊 Productivity Dashboard
- 🌙 Dark Mode Support
- 📱 Responsive UI
- ⚡ Fast and Optimized Performance

# 📂 Project Structure

```bash
src/
│
├── app/                # Next.js App Router
├── components/         # Reusable UI Components
├── features/           # Feature-based modules
├── services/           # API Services
├── hooks/              # Custom React Hooks
├── lib/                # Utility Functions
├── store/              # Global State
├── middleware/         # Route Protection
├── styles/             # Global Styles
└── types/              # Type Definitions
```

# ⚙️ Environment Variables

Create a `.env.local` file in the root directory.

```env
NEXT_PUBLIC_API_URL=http://localhost:8080/api
```

# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/braingrid-frontend.git
```

Move into the project folder:

```bash
cd braingrid-frontend
```

Install dependencies:

```bash
npm install
```

---

# ▶️ Running the Project

Start the development server:

```bash
npm run dev
```

The application will run on:

```txt
http://localhost:3000
```

---

# 🔑 Authentication Flow

1. User registers an account
2. User logs in
3. Backend returns JWT token
4. Token stored securely
5. Protected routes validate authentication
